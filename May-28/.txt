# What We Learned Today

## 1. Difference Between Bastion Host and Jump Box

### Bastion Host

* Azure-managed secure SSH/RDP access
* Browser-based access
* No public IP required for VMs
* Mainly for secure access

### Jump Box

* Separate VM used for administration
* Tools installed inside it
* Used for kubectl, terraform, docker, etc.
* Manual management required

### Important Understanding

Bastion gives access TO VM.

Jump Box IS a VM where tools exist.

# 2. Azure AKS Availability Zone Error

Error:

AvailabilityZoneNotSupported

Reason:

* Central India region does not support availability zones for AKS node pools.

Fix:

* Remove Availability Zones while creating AKS.

# 9. Microservices Understanding

One App Service = One Microservice

Examples:

* Auth Service → Separate App Service
* Frontend → Separate App Service

Why?
Because App Service is not a Kubernetes orchestrator.

# 19. Biggest Concept Learned

Azure App Service is NOT Kubernetes.

It runs:

* one application
* one runtime
* one service

Per App Service instance.

For multiple microservices:

* multiple App Services are created.
